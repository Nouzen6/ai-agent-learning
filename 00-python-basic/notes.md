# Python Notes

## Lesson 1: Variables, Data Types, And Print

### 1. What Is Python?

Python is a programming language. In this learning path, we use it mainly to:

- Process text and files.
- Call APIs.
- Build small tools.
- Build RAG and Agent projects.

### 2. Variable

A variable is a name that stores a value.

```python
name = "Eason"
age = 20
```

You can read this as:

```text
Put the text "Eason" into the variable name.
Put the number 20 into the variable age.
```

### 3. Common Data Types

```python
name = "Eason"      # str, text
age = 20            # int, integer
height = 1.75       # float, decimal number
is_student = True   # bool, True or False
```

### 4. Print

`print` outputs information to the terminal.

```python
print(name)
print(age)
```

### 5. f-string

An f-string helps combine variables and text.

```python
print(f"My name is {name}, and I am {age} years old.")
```

### Key Idea

Programming is not memorizing syntax. It is learning how to describe a process clearly enough that the computer can execute it.
