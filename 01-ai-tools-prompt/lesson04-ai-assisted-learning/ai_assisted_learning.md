## 1. 本课目标

学会用 AI 辅助学习，而不是直接依赖 AI 给答案。

## 2. AI 辅助学习的三种方式

### 2.1 总结

让 AI 把复杂内容变得更清楚。

示例 Prompt：

```text
请帮我总结这段内容。
要求：
1. 用一句话说明主题
2. 列出 5 个关键点
3. 标出 3 个必须理解的概念
4. 给我 3 个自测问题
```
### 2.2 提问
让 AI 根据学习内容向我提问。
示例 Prompt：
请根据上面的内容，问我 5 个问题。
问题从简单到困难排列。
先不要给答案，等我回答后再点评。
2.3 检查理解
让我先说出自己的理解，再让 AI 检查。
示例 Prompt：
这是我对某个知识点的理解：
……

请检查我的理解是否准确。
如果有不完整的地方，请指出并用初学者能懂的方式补充。

## 3. AI 学习闭环
学习资料 -> AI 总结 -> 我自己复述 -> AI 检查 -> AI 出题 -> 我完成练习 -> 复盘记录

## 4. 我的理解
AI 不应该直接替我学习，而应该帮助我总结、提问、检查理解和复盘。
真正重要的是我能不能用自己的话讲出来，并完成练习。

## 5. AI 辅助学习练习

### 练习 1：总结 Prompt

```text
背景：
我正在学习 API，之前已经学过 Python、requests、状态码和 headers，但还没有完全理解 API 的整体概念。

目标：
请帮我总结“什么是 API”，让我能用自己的话解释 API 的作用。

限制：
1. 请从初学者角度讲解。
2. 不要使用太多专业术语。
3. 请结合 GitHub API 举一个简单例子。
4. 不要只给定义，要说明它在实际开发中有什么用。

输出格式：
请用 Markdown 输出，包含：
1. 一句话解释 API
2. API 的作用
3. 一个生活类比
4. 一个 GitHub API 示例
5. 3 个自测问题
```
### 练习2：提问 Prompt
背景：
我正在学习 Git 和 GitHub，已经使用过 git add、git commit 和 git push，但还容易混淆它们的作用。

目标：
请根据“git add / git commit / git push 的区别”向我提问，检查我是否真正理解。

限制：
1. 先只问问题，不要直接给答案。
2. 等我回答后，再逐题点评。
3. 问题要从简单到困难排列。
4. 如果我回答错了，请用通俗语言解释原因。
5. 最后请给我一个小练习，让我描述一次完整的 Git 提交流程。

输出格式：
请用编号列表输出 5 个问题。

### 练习 3：检查理解 Prompt

背景：
我正在学习 Python requests 调用 API，下面是我对 requests 的理解。

目标：
请检查我的理解是否准确，指出有没有错误或不完整的地方。

限制：
1. 不要直接扩展到复杂内容。
2. 请重点检查 requests、GET 请求、状态码、headers、JSON 这几个概念。
3. 如果我的理解有问题，请先指出问题，再给出正确解释。
4. 请用初学者能听懂的语言讲解。

输出格式：
请按照以下结构回答：
1. 我的理解中正确的部分
2. 我的理解中不完整的部分
3. 补充解释
4. 一个小练习题
