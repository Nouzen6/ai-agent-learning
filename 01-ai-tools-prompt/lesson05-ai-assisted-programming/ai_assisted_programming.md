让 AI 解释代码时，不应该只说：

```text

```
更好的方式是说明：
我的基础

我想重点理解什么

## 4. 解释代码 Prompt 模板

背景：
我正在学习 Python，目前已经学过变量、函数、文件读取、JSON 和 requests。

目标：
请帮我解释下面这段代码的作用。

限制：
1. 请从初学者角度解释。
2. 不要只逐行翻译，要先说明整体功能。
3. 重点解释函数之间的关系和数据流动过程。
4. 如果有我可能不懂的语法，请单独说明。

输出格式：
请按照以下结构回答：
1. 这段代码整体在做什么
2. 主要函数/模块说明
3. 数据是如何流动的
4. 关键代码逐段解释
5. 我需要重点掌握的知识点
6. 可能的改进建议

## 5. 读代码的 4 个层次

读代码时可以按 4 层理解：
整体功能
输入和输出
执行流程
关键细节

## 6. 我的理解

让 AI 解释代码时，不能只让它逐行翻译。
更好的方式是先理解整体功能、输入输出、执行流程，再看关键代码细节。

## 9. Lesson 05B：让 AI 写代码

### 9.1 重要程度

重要程度：高

原因：
后面的 LLM API 应用、RAG、Agent、minimal SWE Agent 都需要让 AI 辅助生成代码。
但我必须学会控制需求范围，不能盲目复制 AI 生成的代码。

### 9.2 让 AI 写代码的流程

推荐流程：

1. 说明背景
2. 说明目标
3. 限制技术范围
4. 让 AI 先拆步骤
5. 确认步骤后再写代码
6. 运行代码
7. 把报错发回去
8. 让 AI 继续修复

### 9.3 写代码 Prompt 模板

```text
背景：
我正在学习 Python，目前已经学过文件读取、JSON、命令行参数、异常处理和 requests。

目标：
请帮我写一个 Python 小工具，用来读取一个 Markdown 学习日志，并统计指定关键词出现次数。

限制：
1. 请只使用 Python 标准库。
2. 请先说明实现步骤，不要直接给代码。
3. 代码要适合初学者理解。
4. 每个函数职责要清楚。
5. 请包含基本异常处理。
6. 不要加入我没有要求的复杂功能。

输出格式：
请先输出：
1. 实现步骤
2. 文件结构
3. 完整代码
4. 运行命令示例
5. 如何检查运行结果
```

## 11. Lesson 05C：让 AI debug

### 11.1 重要程度

就业重要度：很高

原因：
Agent 开发工程师需要能读懂报错、定位问题、修复代码并验证结果。
后面的 minimal SWE Agent 本质上就是自动执行这个流程。

### 11.2 debug 的核心信息

让 AI debug 时，应该提供：

1. 代码
2. 运行命令
3. 完整报错信息
4. 期望结果
5. 实际结果
6. 我已经尝试过什么

### 11.3 debug Prompt 模板

```text
背景：
我正在学习 Python，目前在运行一个小项目。

代码：
……

运行命令：
……

完整报错信息：
……

期望结果：
……

实际结果：
……

我已经尝试过：
……

目标：
请帮我分析错误原因，并告诉我如何修复。

限制：
1. 请先解释错误原因，不要直接给修改后的代码。
2. 请指出最可能出错的文件和行号。
3. 尽量保留我原来的代码结构。
4. 修改要适合初学者理解。
5. 如果有多个可能原因，请按可能性排序。

输出格式：
请按照以下结构回答：
1. 错误类型
2. 错误原因
3. 最可能出错的位置
4. 修改方案
5. 修改后的代码片段
6. 如何重新运行验证
```

### 11.4 读报错的顺序

读 Python 报错时，按这个顺序：

1. 看最后一行，找到错误类型和错误原因
2. 看文件名和行号，找到错误位置
3. 往上看调用链，理解程序是怎么走到这里的
4. 回到代码里检查输入、变量、路径、类型

### 11.5 常见错误类型

| 错误类型 | 常见原因 | 优先检查 |
|---|---|---|
| SyntaxError | 语法写错 | 冒号、括号、缩进、引号 |
| NameError | 变量名不存在 | 变量是否定义、名字是否拼错 |
| TypeError | 类型不匹配 | 字符串、整数、列表是否混用 |
| FileNotFoundError | 文件找不到 | 文件路径、运行目录、文件名 |
| KeyError | 字典里没有这个 key | JSON 数据结构、key 是否存在 |
| ModuleNotFoundError | 模块没安装或环境不对 | conda 环境、pip 安装、解释器 |
| requests.exceptions.RequestException | 网络/API 请求失败 | URL、网络、headers、状态码 |

### 11.6 我的理解

debug 不是把报错直接丢给 AI，而是要给 AI 足够上下文。
我需要提供代码、运行命令、完整报错、期望结果和实际结果。
AI 给出修改建议后，我还要自己运行验证。

### 练习 1：FileNotFoundError

模糊请求：

```text
我的程序找不到文件，帮我看看。
```

改写成结构化 debug Prompt：

```text
背景：
我正在运行 learning_log_analyzer.py，用来读取学习日志并统计关键词。

代码：
这里粘贴相关代码，尤其是读取文件的部分。

运行命令：
python learning_log_analyzer.py learning-log.md --keywords Python API JSON

完整报错信息：
这里粘贴完整 traceback。

期望结果：
程序可以读取 learning-log.md，并统计 Python、API、JSON 出现的次数。

实际结果：
程序报 FileNotFoundError，提示找不到文件。

目标：
请帮我分析为什么找不到文件，并告诉我如何修复。

限制：
1. 请先解释错误原因。
2. 请重点检查文件路径、运行目录和文件名。
3. 不要直接重写整个程序。
4. 请给出最小修改方案。

输出格式：
请按照“错误原因 -> 检查步骤 -> 修改建议 -> 重新运行命令”的结构回答。
```

输出格式：
