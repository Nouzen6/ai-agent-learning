## 3. Lesson 05A：让 AI 解释代码

让 AI 解释代码时，不应该只说：

```text
解释这段代码。
```
更好的方式是说明：
我的基础
代码用途
我想重点理解什么
希望 AI 按什么结构解释

## 4. 解释代码 Prompt 模板

背景：
我正在学习 Python，目前已经学过变量、函数、文件读取、JSON 和 requests。

目标：
请帮我解释下面这段代码的作用。

限制：
1. 请从初学者角度解释。
2. 不要只逐行翻译，要先说明整体功能。
3. 重点解释函数之间的关系和数据流动过程。
4. 如果有我可能不懂的语法，请单独说明。

输出格式：
请按照以下结构回答：
1. 这段代码整体在做什么
2. 主要函数/模块说明
3. 数据是如何流动的
4. 关键代码逐段解释
5. 我需要重点掌握的知识点
6. 可能的改进建议

## 5. 读代码的 4 个层次

读代码时可以按 4 层理解：
整体功能
输入和输出
执行流程
关键细节

## 6. 我的理解

让 AI 解释代码时，不能只让它逐行翻译。
更好的方式是先理解整体功能、输入输出、执行流程，再看关键代码细节。

## 9. Lesson 05B：让 AI 写代码

### 9.1 重要程度

重要程度：高

原因：
后面的 LLM API 应用、RAG、Agent、minimal SWE Agent 都需要让 AI 辅助生成代码。
但我必须学会控制需求范围，不能盲目复制 AI 生成的代码。

### 9.2 让 AI 写代码的流程

推荐流程：

1. 说明背景
2. 说明目标
3. 限制技术范围
4. 让 AI 先拆步骤
5. 确认步骤后再写代码
6. 运行代码
7. 把报错发回去
8. 让 AI 继续修复

### 9.3 写代码 Prompt 模板

```text
背景：
我正在学习 Python，目前已经学过文件读取、JSON、命令行参数、异常处理和 requests。

目标：
请帮我写一个 Python 小工具，用来读取一个 Markdown 学习日志，并统计指定关键词出现次数。

限制：
1. 请只使用 Python 标准库。
2. 请先说明实现步骤，不要直接给代码。
3. 代码要适合初学者理解。
4. 每个函数职责要清楚。
5. 请包含基本异常处理。
6. 不要加入我没有要求的复杂功能。

输出格式：
请先输出：
1. 实现步骤
2. 文件结构
3. 完整代码
4. 运行命令示例
5. 如何检查运行结果
```

## 10. Lesson 05B 练习：让 AI 写代码

练习 1：写一个小工具 Prompt

背景：
我正在学习 Python 和 AI Agent，目前已经学过文件读取、JSON、命令行参数、函数和异常处理。

目标：
请帮我写一个 Python 命令行小工具，用来添加学习记录，并保存到 learning-log.md 文件中。

限制：
1. 请只使用 Python 标准库。
2. 请先说明实现步骤，再给代码。
3. 代码要适合初学者理解。
4. 请使用命令行参数接收学习主题和学习内容。
5. 如果文件不存在，请自动创建。
6. 不要使用数据库、Web 框架或复杂第三方库。

输出格式：
请用 Markdown 输出，包含：
1. 实现步骤
2. 文件结构
3. 完整 Python 代码
4. 运行命令示例
5. 如何检查结果

练习 2：限制 AI 不要写复杂代码

背景：
我正在学习 LLM API 应用开发，已经学过 Python、requests、headers、JSON 和命令行运行 Python 文件。

目标：
请帮我设计一个最小版本的命令行 AI 聊天助手。

限制：
1. 先不要写完整复杂项目。
2. 只做一个 Python 文件。
3. 只实现一次输入、一次请求、一次输出。
4. 暂时不要加入历史对话、数据库、Web 页面、用户登录等功能。
5. 请先解释请求流程，再给代码。
6. 代码要适合初学者理解。

输出格式：
请按照以下结构输出：
1. 最小版本功能说明
2. 请求流程
3. 需要准备的配置
4. 完整代码
5. 运行命令
6. 下一步可以扩展的功能
