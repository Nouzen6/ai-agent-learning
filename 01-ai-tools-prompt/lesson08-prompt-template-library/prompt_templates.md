# Stage 1 Lesson 08: Prompt 模板库

## 1. 学习总结模板

背景：
……

目标：
请总结这段内容，让我能快速理解重点。

限制：
1. 用初学者能懂的语言
2. 不要直接照抄原文
3. 说明关键概念和易错点

输出格式：
请用 Markdown 输出，包含：
1. 一句话总结
2. 关键点
3. 易错点
4. 自测问题

## 2. 概念解释模板

背景：
我正在学习……

目标：
请解释这个概念。

限制：
1. 从基础开始
2. 先讲整体，再讲细节
3. 用例子说明

输出格式：
请按以下顺序回答：
1. 概念是什么
2. 为什么重要
3. 一个简单例子
4. 一个练习题

## 3. 任务拆解模板

背景：
我想完成……

目标：
请把这个任务拆成多个小步骤。

限制：
1. 每一步都要具体
2. 每一步都要适合初学者
3. 不要直接给最终答案

输出格式：
请用表格输出：
步骤、任务、目的、完成标志

## 4. 写代码模板

背景：
我正在学习 Python，目前已经学过……

目标：
请帮我写一个小工具。

限制：
1. 先说步骤，不要直接给代码
2. 代码要简单
3. 只使用必要的库
4. 不要加入额外复杂功能

输出格式：
请先输出实现步骤，再输出代码，最后说明运行方法。

## 5. Debug 模板

背景：
我在运行一个 Python 程序时遇到了问题。

代码：
……

运行命令：
……

完整报错：
……

期望结果：
……

实际结果：
……

目标：
请帮我分析错误原因并修复。

输出格式：
请按照“错误原因 -> 修改建议 -> 修改后的代码 -> 验证方法”输出。

## 6. 验证模板

请检查你的答案是否有问题。
如果有不确定的地方，请标出来，并告诉我怎么验证。
