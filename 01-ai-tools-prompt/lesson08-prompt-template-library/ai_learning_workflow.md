# Stage 1 Lesson 08: AI 学习工作流

## 我的学习流程

1. 明确问题
2. 写出结构化 Prompt
3. 让 AI 给出答案
4. 自己复述一遍
5. 检查 AI 答案是否可靠
6. 动手实践
7. 记录笔记
8. 把好用的 Prompt 加进模板库

## 我的原则

- 对后续项目帮助大的知识点，要深入学
- 对当前目标帮助不大的知识点，只需要了解
- AI 的答案要验证，不能盲信
- 学习必须和项目结合
- 每学一课都要留下可复用的产物

## 我的理解

Prompt 模板库会让我以后更快地和 AI 协作。
它不是死记硬背，而是把常用问题变成稳定的工作流。
