## 1. 本课目标

学会把一个模糊的大任务拆成多个清楚的小步骤。

## 2. 为什么要任务拆解

如果直接把大任务丢给 AI，AI 可能会：
- 理解错目标
- 一次输出太多
- 给出太复杂的方案
- 写出我看不懂的代码
- 忽略测试和检查

任务拆解可以让我一步一步完成，并且每一步都能检查结果。

## 3. 任务拆解模板

```text
背景：
我想完成……

目标：
请不要直接给最终答案。
请先把这个任务拆成适合初学者完成的步骤。

限制：
每一步都要具体、可执行。
每一步不要太大。
如果涉及代码，请先说明思路，再写代码。

输出格式：
请用 Markdown 表格输出，包含：
步骤编号、任务、目的、完成标志。

```

## 4.任务拆解练习
练习1：帮我学会使用 GitHub。
背景：我正在学习如何开发agent，想将过程上传到github上面
目标：请帮我把学会使用GitHub拆解成5-8个小步骤
限制：
每一步都适合初学者完成
每一步都要配上相应的讲解
讲解要通俗易懂，小白也能理解
输出：请以Markdown表格输出，包含：1、步骤编号2、步骤3、目的4、完成标识

### 练习 1：学会使用 GitHub

| 步骤 | 任务 | 目的 | 完成标志 |
|---|---|---|---|
| 1 | 注册并登录 GitHub | 拥有自己的远程代码仓库账号 | 能打开自己的 GitHub 主页 |
| 2 | 创建一个新仓库 | 学会建立项目存放位置 | GitHub 上出现新仓库 |
| 3 | 在本地初始化 Git 仓库 | 让本地项目可以被 Git 管理 | 执行 `git status` 能看到仓库状态 |
| 4 | 添加并提交文件 | 学会保存一个版本 | 执行 `git log` 能看到提交记录 |
| 5 | 连接远程仓库 | 让本地仓库和 GitHub 仓库关联 | 执行 `git remote -v` 能看到 GitHub 地址 |
| 6 | 推送到 GitHub | 把本地代码上传到远程仓库 | GitHub 页面能看到文件 |
| 7 | 修改 README | 学会展示项目说明 | GitHub 仓库首页能看到说明文字 |
| 8 | 复盘常用命令 | 巩固 GitHub 工作流 | 能说出 add、commit、push 的作用 |

练习2：帮我做一个命令行 AI 聊天助手
背景：我了解基础python知识，api调用
目标：请帮我把做一个命令行AI聊天助手拆解成6-10个步骤
限制
不要直接给出代码
每一步都要适合初学者完成
每一步都要配上代码和讲解
讲解要求通俗易懂
输出：请以Markdown格式输出
包含：1、步骤编号
2、步骤
3、目的
4、讲解、
5、完成标识

### 练习 2：做一个命令行 AI 聊天助手

| 步骤 | 任务 | 目的 | 完成标志 |
|---|---|---|---|
| 1 | 明确助手功能 | 确定最小版本要做什么 | 写出输入和输出示例 |
| 2 | 创建 Python 文件 | 准备项目入口 | 有 `cli_ai_assistant.py` 文件 |
| 3 | 读取用户输入 | 实现命令行交互 | 程序能接收用户输入 |
| 4 | 准备 API 请求结构 | 明确请求需要哪些数据 | 写出 URL、headers、body |
| 5 | 调用 LLM API | 让程序获得 AI 回复 | 能打印模型返回内容 |
| 6 | 加入循环对话 | 支持连续聊天 | 输入多轮问题都能回复 |
| 7 | 添加退出命令 | 让程序可以正常结束 | 输入 `exit` 可以退出 |
| 8 | 处理异常 | 避免程序直接崩溃 | API 出错时显示友好提示 |
| 9 | 整理 README | 记录运行方法 | README 有安装和运行说明 |

练习3：帮我做一个个人知识库问答助手。
背景：我了解基础python知识
目标：把做一个个人知识库问答助手拆解成8-12个步骤
限制：
直接给出代码
每部分代码都要配上讲解
讲解要通俗易懂
输出：请以Markdown格式输出
包含：1、步骤编号
2、步骤
3、目的
4、讲解、
5、完成标识

### 练习 3：做一个个人知识库问答助手

| 步骤 | 任务 | 目的 | 完成标志 |
|---|---|---|---|
| 1 | 准备知识库文件夹 | 存放自己的资料 | 有 `knowledge_base/` 目录 |
| 2 | 读取 Markdown 或 TXT 文件 | 让程序获取资料内容 | 能打印文件文本 |
| 3 | 清洗文本 | 去掉无用空行和杂乱内容 | 文本更适合处理 |
| 4 | 切分文本 chunk | 把长文拆成小段 | 每段长度适中 |
| 5 | 生成 embedding | 把文本变成向量 | 每个 chunk 有对应向量 |
| 6 | 保存向量数据 | 方便后续检索 | 向量和原文片段能被保存 |
| 7 | 根据问题检索相关片段 | 找到最可能有用的资料 | 返回 top-k 文本片段 |
| 8 | 构造 Prompt | 把资料片段放进问题上下文 | Prompt 中包含检索结果 |
| 9 | 调用 LLM 生成回答 | 让 AI 基于资料回答 | 输出自然语言答案 |
| 10 | 添加引用来源 | 防止答案没依据 | 回答中能看到来源文件 |
| 11 | 测试问答效果 | 检查回答是否忠于资料 | 准备 3 个测试问题 |
| 12 | 整理项目说明 | 记录使用方法 | README 有运行步骤 |
