# Stage 1 Lesson 02: Prompt 基本结构

## 1. 本课目标

学会使用 Prompt 的 4 个核心部分：

- 背景 Context
- 目标 Goal
- 限制 Constraints
- 输出格式 Output Format

## 2. Prompt 四要素

### 2.1 背景 Context

背景用来告诉 AI 当前情况，例如：
- 我是谁
- 我现在的基础
- 我正在做什么
- 我已经尝试过什么

### 2.2 目标 Goal

目标用来告诉 AI 你希望它完成什么任务，例如：
- 解释一个概念
- 写一段代码
- 检查一个错误
- 总结一篇文章

### 2.3 限制 Constraints

限制用来告诉 AI 边界，例如：
- 从基础开始讲
- 不要使用复杂术语
- 不要直接给答案
- 只使用 Python 标准库
- 输出不要超过 300 字

### 2.4 输出格式 Output Format

输出格式用来告诉 AI 答案长什么样，例如：
- Markdown
- JSON
- 表格
- 分步骤说明
- 先代码后解释

## 3. Prompt 模板

```text
背景：
……

目标：
……

限制：
……

输出格式：
……
```

## 4. 示例

背景：
我正在学习 AI Agent，目前已经完成 Python、Git、requests 和 GitHub API 的基础学习。

目标：
请解释什么是 Prompt Engineering。

限制：
请从初学者角度讲解，不要使用太多专业术语。
每个概念都要配一个简单例子。

输出格式：
请用 Markdown 输出，分为“概念解释、为什么重要、一个练习题”三个部分。

## 5. 我的理解
Prompt 不是简单提问，而是给 AI 的任务说明书。
背景让 AI 知道我的情况，目标告诉 AI 要做什么，限制控制范围，输出格式决定结果怎么呈现。

## 6. Prompt 结构练习
练习 1
帮我学 Python。

练习 2
帮我 debug。

练习 3
总结这篇文章。

1:帮我学python
背景：
1、了解数据基础类型和变量
2、了解基础函数的定义和使用
3、了解循环和递归等基础结构
4、了解基础面对对象编程
目标：
掌握学习ai agent开发所需要的python知识
限制：
1、要求语言通俗易懂
2、每个阶段都要详细讲解并且给出例子
3、阶段的结尾要有练习环节
输出格式：
以Markdown输出，按需求分为多个部分

2:帮我debug
背景：
以下是我写的关键词分析程序：xxx
实际报错是：
我期望程序表现是：

目标：请帮我找出错误原因，并告诉我如何修改。
限制：
1、不能更改基本功能
2、每段内容要有讲解
3、 请先解释错误原因，再给出修改后的代码。
4、 修改内容要适合 Python 初学者理解。
输出格式：
直接给出python程序

3:总结这篇文章
背景：前三章已经阅读并基本了解
目标：总结第四章的内容
限制：
1、要求语言通俗易懂
2、关键的地方要标注出来
3、结构简洁，不能直接照搬原文
4、每个部分要有对应的讲解
5、配上相应的树状图
6.、我可以继续追问的 3 个问题
输出格式：请按Markdown格式输出
