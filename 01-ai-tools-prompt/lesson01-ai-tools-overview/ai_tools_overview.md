# Stage 1 Lesson 01: 主流 AI 工具怎么用

## 1. 本课目标

学会把 AI 当作学习和开发助手，而不是只用来闲聊。

## 2. 常见 AI 工具

| 工具 | 适合任务 | 我的理解 |
|---|---|---|
| ChatGPT / Codex | 学习、编程、项目拆解、代码解释 | 我的主要学习助手 |
| Claude | 长文阅读、写作、总结 | 适合处理大段文字 |
| Kimi | 中文资料阅读、长文本总结 | 适合中文材料 |
| DeepSeek | 编程、推理、问答 | 适合练习和对比答案 |

## 3. 使用 AI 的三种模式

### 学习助手

让 AI 解释概念、举例、出练习、检查理解。

### 开发助手

让 AI 解释代码、找 bug、写函数、设计项目结构。

### 资料助手

让 AI 总结文档、提取重点、生成表格、整理知识点。

## 4. 不推荐的用法

只说：
“帮我学 AI”
“帮我写代码”
“这个怎么做”

这些问题太模糊，AI 很容易给出空泛答案。

## 5. 推荐的用法

说明：
- 我现在的水平
- 我想完成什么
- 我已经做了什么
- 我希望输出什么格式
- 我希望 AI 怎么帮助我

## 6. 我的总结

AI 工具不是替我学习，而是帮助我更快理解、练习、验证和整理。

## 7. AI 工具使用练习

练习 1：学习助手场景
请教会我如何同时使用多agent
目前已熟练掌握单agent使用方法，api调用方法
从基础开始逐步讲解，仅用语言讲解


练习 2：开发助手场景
帮我做一个前端网页
要有可交互按键，内容是我的作品：
直接输出代码给我
输出完代码之后，逐步讲解


练习 3：资料助手场景
从各个方面总结这篇文章
要求有5章内容，分为多个小节
从多个维度进行讲解，内容要求通俗易懂


1.请教我如何同时使用多个 Agent。

我的基础：
我已经学习过单个 Agent 的基本使用方法，也了解 API 调用的基本流程。

学习要求：
请从基础开始讲解，不要直接跳到复杂框架。
先解释“多个 Agent 协作”是什么意思，再举一个简单例子。
讲解时只使用通俗语言，避免太多专业术语。

输出格式：
请按照“概念解释 -> 简单例子 -> 常见使用场景 -> 一个小练习”的结构回答。

2.请帮我做一个简单的前端网页。

背景：
这是我的个人学习作品，用来展示我的 AI Agent 学习路线。

要求：
页面需要包含标题、学习阶段列表、每个阶段的简短说明。
请直接给出 HTML、CSS 和 JavaScript 代码。
代码要适合初学者阅读。

输出方式：
先给出完整代码，再逐步解释代码结构。
解释时请说明每个部分的作用。

3.请帮我总结下面这篇文章。

要求：
从多个角度进行总结，至少包括：
1. 文章主题
2. 核心观点
3. 关键概念
4. 适合初学者理解的解释
5. 我可以继续追问的问题

输出格式：
请使用 Markdown。
内容分成多个小节。
语言要通俗易懂，不要只照抄原文。
