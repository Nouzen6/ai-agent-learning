# AI Agent 开发学习路线

学习路线分为六个阶段：

Stage 0 学习 Python、Git 和开发环境基础。

Stage 1 学习 AI 工具使用、Prompt 结构、任务拆解和结果验证。

Stage 2 学习 LLM API，包括 HTTP 请求、对话上下文、SSE 流式输出、结构化 JSON、异常处理和 Mock 测试。

Stage 3 学习 RAG，包括文档读取、文本清洗、chunk、embedding、向量检索、Prompt 构造、评估和优化。

Stage 4 学习 Agent，包括工具调用、任务规划、执行循环和状态管理。

Stage 5 实现 minimal SWE Agent，使 Agent 能够读取代码、修改文件、运行命令并根据结果继续行动。
